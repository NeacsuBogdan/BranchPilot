# Domain Outline

Stage 0 does not implement the business model yet, but the product direction is fixed around the following tenant-scoped capabilities:

- Tenant
- Location
- User
- Membership
- Role
- Permission
- EmployeeProfile
- Customer
- CatalogItem
- Category
- TaxProfile
- LocationPrice
- Promotion
- Booking
- BookingLine
- Order
- OrderLine
- AuditLog
- Notification
- RefreshToken
- JobRunHistory

Domain implementation begins in later stages, starting with authentication, tenancy, and location management.
